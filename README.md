# Gemini AI Chatbot 🤖

A simple AI chatbot built using the Google Gemini API and Gradio.

## Features

- Google Gemini API integration
- Interactive chatbot interface
- Built using Gradio
- Uses Gemini 3.6 Flash model
- Simple and user-friendly interface

## Technologies Used

- Python
- Google Gemini API
- Gradio
- Google Colab

## Project Description

This project demonstrates how to build a simple AI chatbot using Google's Gemini API. The chatbot allows users to enter messages and receive AI-generated responses through an interactive Gradio interface.

## How to Run

1. Open the Jupyter Notebook.
2. Install the required libraries.
3. Add your Gemini API key securely.
4. Run all the cells.
5. Open the Gradio interface and start chatting.
